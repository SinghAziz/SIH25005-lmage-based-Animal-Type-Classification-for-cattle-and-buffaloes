# SIH25005 — Image-based Animal Type Classification for cattle and buffaloes

AI can automate Animal Type Classification (ATC) in dairy farming by analyzing cattle images to extract body structure traits and generate standardized, unbiased scores. Integrated with Bharat Pashudhan App, it ensures accurate, consistent, and efficient recording, reducing human error in PT and PS programs under RGM.

## Quick start

```bash
./run.sh
```

Checks for Python 3 and Flutter (installing them if missing), sets up `backend/venv`,
starts the API on `:8082`, and serves the web app on `:8083` — then Ctrl+C stops both.

| Variable | Default | |
|---|---|---|
| `WEB_PORT` | `8083` | app port |
| `BACKEND_PORT` | `8082` | API port |
| `API_URL` | `http://localhost:8082/predict` | set to your LAN IP to open the app from a phone |

Linux/macOS/WSL only.

## Backend

Create the virtual environment once, then activate it whenever you work on the backend:

```bash
cd backend
python3 -m venv venv

# Activate (Linux/macOS)
source venv/bin/activate
# Windows: venv\Scripts\activate

pip install -r requirements.txt
uvicorn app:app --host 0.0.0.0 --port 8000
```

Run `deactivate` to leave the environment.

- `POST /predict` accepts a multipart image (`file`) and returns breed, height, width, weight and daily milk yield.
- Model paths are resolved relative to `backend/app.py`, so the server can be started from any directory.
